One-time DM device setup
Firebase gives this browser an anonymous ID automatically. Copy the rules for this device and paste them into Firebase → Realtime Database → Rules → Publish. No login is required.

Keep this browser profile for DM controls; clearing browser storage can generate a new ID. Only the browser ID in your published rules can edit online data.
