# Project Grim 2.1.4: sway control

- **New:** World → Weather → **Tree & grass sway**, from *Still* to strong. Default 50%: a gentle lean with the wind.
- Whatever the wind speed, a tree crown now leans at most about 6°. Trees bend from the root as one piece (2.1.1 behaviour), so branches and canopies stay attached.
- If trees still stretch or fly apart after updating, the browser is showing a cached copy of the old code. Press **Ctrl+Shift+R** on the GM page and on the TV.

Tests: 47/47 unit and regression, 16/16 page checks.
